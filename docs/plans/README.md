# Plans

Formalization plans, as described in the repository README. Each project gets a directory
containing a root plan (`00-overview.md`) and a tree of sub-plans.

| project | root plan | source |
|---|---|---|
| Convex analysis | [`convex-analysis/00-overview.md`](convex-analysis/00-overview.md) | R. T. Rockafellar, *Convex Analysis*, Princeton, 1970 |

A plan is a living document: it is written before formalization begins, reviewed whenever the
formalization pushes back on it, and updated when the backbone changes shape. The `Status` section
of a root plan records what has actually been formalized.
